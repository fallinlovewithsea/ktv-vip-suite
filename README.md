# 璀璨之夜 · VIP KTV 包厢

豪华 VIP KTV 包厢的交互式 HTML 演示，包含欢唱、酒水、游戏、休憩等多个功能区。

## 功能区

- 🎤 **欢唱区** - 真实舞台 + 激光效果 + 频谱可视化 + 8 首歌曲在线播放
- 🍸 **酒水区** - 真实酒吧场景 + 10 款精选酒水
- 🎲 **游戏区** - 双骰游戏 / 老虎机 / 记忆翻牌
- 🛁 **休憩区** - 总统套房配置 + 氛围控制
- 🛋️ **沙发区** - U 型真皮沙发 + 多人嘉宾

## 技术栈

- 纯 HTML + CSS + JavaScript（无构建工具、无依赖）
- Web Audio API 实时频谱分析
- Unsplash 真实图片素材
- SoundHelix 公开音乐流

## 本地运行

```bash
# 直接打开 index.html 即可，或：
python -m http.server 8000
# 然后访问 http://localhost:8000
```
